# homebrew-tap

Homebrew tap for [GioPalusa](https://github.com/GioPalusa) tools.

## Available formulae

### srt-download

Download subtitles for local video files, recursively.

```bash
brew install GioPalusa/homebrew-tap/srt-download
```

See the [project repository](https://github.com/GioPalusa/SRT-downloader) for usage and docs.

---

Formulae in `Formula/` are updated automatically by the
[publish-package-managers](https://github.com/GioPalusa/SRT-downloader/actions)
workflow on each tagged release.
